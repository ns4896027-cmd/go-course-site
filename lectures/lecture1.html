Лекция 1. Введение в Go

Длительность лекции: 60 минут
Уровень: Начинающий

📜 История создания Go

Конец 2000-х годов. Компания Google столкнулась с проблемой масштабирования программных систем. Тысячи разработчиков, миллионы строк кода на C++ и Java. Компиляция больших проектов на C++ занимала часы, а Java была слишком тяжеловесной.

Три инженера Google задались вопросом: «А можем ли мы создать язык, который сочетал бы производительность C++ с простотой Python?»

Создатели языка

Роберт Гризмер (Robert Griesemer)

Работал над реализациями JavaScript (V8) и Java (HotSpot)

Роб Пайк (Rob Pike)

Легенда Unix, соавтор UTF-8

Кен Томпсон (Ken Thompson)

Один из создателей Unix и языка B, лауреат премии Тьюринга

Хронология

2007 г.
Начало разработки (внутренний 20%-ный проект)
2009 г.
Официальный анонс 10 ноября
2012 г.
Выход версии 1.0 — обещание обратной совместимости

📍 Где применяется Go

Go стал стандартом в целых индустриях. Вот лишь несколько примеров:

Облачная инфраструктура

Docker, Kubernetes, Terraform, Prometheus

Высоконагруженные бэкенд-сервисы

Avito, Ozon, Wildberries, YouTube

Сетевые приложения

Caddy, Traefik, VPN-сервисы

CLI-утилиты

GitHub CLI, Hugo, Docker CLI

🎯 Для чего нужен Go

Go решает конкретные задачи, и его выбор обычно обусловлен следующими целями:

  • Микросервисная архитектура — сервисы быстро запускаются и мало весят
  • Сетевые сервисы — высокая нагрузка на соединения (WebSocket, HTTP/2)
  • Инструменты DevOps — работают везде без установки зависимостей
  • Замена Python там, где нужна производительность
Чего НЕ делают на Go: системное программирование (ядра ОС, драйверы), десктопные приложения с GUI, Data Science, AAA-игры.

💡 Философия Go

Главный девиз языка, сформулированный Робом Пайком: «Less is exponentially more» (Меньшее — экспоненциально лучшее).

Простота и читаемость

Код пишется один раз, а читается сотни раз. В Go всего 25 ключевых слов, нет перегрузки функций, нет классов и наследования. Утилита go fmt автоматически приводит код к единому стилю — в сообществе Go нет споров о форматировании.

Явность лучше неявного

Нет неявных преобразований типов. Нет исключений (exceptions) — ошибка — это просто ещё одно возвращаемое значение. Это заставляет разработчика думать об обработке ошибок здесь и сейчас.

Эффективность

Компиляция в машинный код, быстрая компиляция (даже большие проекты за секунды), эффективный сборщик мусора с минимальными задержками.

⚡ Ключевые особенности языка

Статическая типизация

Ошибки типов на этапе компиляции, а не в рантайме

Быстрая компиляция

Проекты компилируются за секунды

Встроенная конкурентность

Горутины (легковесные потоки, ~2 КБ) и каналы для общения

Один бинарный файл

Статическая компиляция — нет зависимостей, просто скопируйте и запустите

Кросс-компиляция

Сборка под любую платформу из коробки

Богатая стандартная библиотека

net/http, encoding/json, crypto, testing — «батарейки в комплекте»
