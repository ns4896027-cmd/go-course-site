Лекция 2. Базовые типы данных. Переменные и константы

Длительность лекции: 45 минут
Уровень: Начинающий
Темы: Целочисленные типы, числа с плавающей точкой, строки, bool, переменные, константы, iota

🔢 Целочисленные типы

В Go есть несколько целочисленных типов, различающихся диапазоном значений и размером в памяти:

ТипДиапазонРазмер
int8-128 до 1271 байт
int16-32768 до 327672 байта
int32-2147483648 до 21474836474 байта
int64-9·10¹⁸ до 9·10¹⁸8 байт
uint80 до 2551 байт
uint160 до 655352 байта
uint320 до 42949672954 байта
uint640 до 1.8·10¹⁹8 байт
byteсиноним uint81 байт
runeсиноним int324 байта
int32 или 64 бита (зависит от платформы)4 или 8 байт
uintбеззнаковый, 32 или 64 бита4 или 8 байт
Важно: Типы int и uint имеют размер, зависящий от платформы (32 бита на 32-разрядных системах, 64 бита на 64-разрядных).

✅ Логический тип bool

Может принимать одно из двух значений: true (истина) или false (ложь).

var isActive bool = true
var isFinished bool = false

📝 Строки

Строка — это последовательность символов, заключённая в двойные кавычки:

var name string = "Hello Go"

Управляющие последовательности

ПоследовательностьЗначение
\nновая строка
\rвозврат каретки
\tтабуляция
\"двойная кавычка
\\обратный слеш

🎯 Значения по умолчанию (zero values)

Если переменной не присвоено значение, она получает значение по умолчанию:

ТипЗначение по умолчанию
Числовые типы0
boolfalse
string"" (пустая строка)
 
var x int          // 0
var y float64      // 0
var z bool         // false
var s string       // ""
Важно: В Go нет null или undefined. У каждой переменной всегда есть значение.

📦 Объявление переменных

Полное объявление

var name string
name = "Tom"

// Или сразу с инициализацией
var name string = "Tom"

Групповое объявление

var (
    name string = "Tom"
    age  int    = 27
)

Краткое объявление (только внутри функций)

name := "Tom"
age := 27

Определение типа переменной

var x = 42           // тип int
var y = 3.14         // тип float64
var z = "Hello"      // тип string

// Узнать тип переменной
fmt.Printf("%T\n", x)   // int

🔒 Константы

Константы — это значения, которые нельзя изменить после объявления.

const pi float64 = 3.1415
const appName = "MyApp"

// Групповое объявление
const (
    pi = 3.1415
    e  = 2.7182
)

Автоматическая инициализация констант

const (
    a = 1
    b      // b = 1
    c      // c = 1
    d = 3
    f      // f = 3
)
fmt.Println(a, b, c, d, f) // 1, 1, 1, 3, 3

Идентификатор iota

iota — счётчик, который увеличивается с объявлением каждой новой константы в блоке const.

const (
    C0 = iota  // 0
    C1         // 1
    C2         // 2
)
fmt.Println(C0, C1, C2) // 0, 1, 2

// iota сбрасывается в каждом новом блоке const
const (
    C3 = iota  // 0
)
