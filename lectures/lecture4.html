Лекция 4. Коллекции: массивы, срезы и карты

Длительность лекции: 75 минут
Уровень: Средний
Темы: Массивы, срезы (slices), операции со срезами

📊 Массивы

Массив — это последовательность элементов определённого типа фиксированной длины.

Объявление и инициализация

// Полная инициализация
var numbers [5]int
var primes = [5]int{2, 3, 5, 7, 11}

// Автоматическое определение длины
var fruits = [...]string{"яблоко", "груша", "банан"}

// Частичная инициализация
var temps = [5]int{10, 20}  // [10, 20, 0, 0, 0]

Доступ к элементам

numbers := [5]int{10, 20, 30, 40, 50}
fmt.Println(numbers[0])  // 10
fmt.Println(numbers[2])  // 30
numbers[1] = 25          // изменение элемента

Перебор массива

numbers := [5]int{10, 20, 30, 40, 50}

// Способ 1: классический for
for i := 0; i < len(numbers); i++ {
    fmt.Println(numbers[i])
}

// Способ 2: range
for index, value := range numbers {
    fmt.Printf("index: %d, value: %d\n", index, value)
}

Особенности массивов

1. Массивы передаются по значению (копируются) 
func modify(arr [3]int) {
    arr[0] = 100
}

func main() {
    a := [3]int{1, 2, 3}
    modify(a)
    fmt.Println(a)  // [1, 2, 3] — не изменился!
}
2. Массивы сравниваются поэлементно 
a := [3]int{1, 2, 3}
b := [3]int{1, 2, 3}
c := [3]int{1, 2, 4}
fmt.Println(a == b)  // true
fmt.Println(a == c)  // false

Многомерные массивы

// Двумерный массив 3x2
numbers := [3][2]int{
    {1, 2},
    {4, 5},
    {7, 8},
}

// Доступ к элементам
fmt.Println(numbers[0][0])  // 1
fmt.Println(numbers[1][1])  // 5

// Длина многомерного массива — первая размерность
fmt.Println(len(numbers))  // 3

✂️ Срезы (Slices)

Срез — это последовательность элементов одного типа переменной длины. В отличие от массивов, длина среза может динамически меняться.

Определение среза

var users []string                    // пустой срез
users := []string{"Tom", "Alice"}     // литерал среза
users := make([]string, 3)            // через make (длина 3, емкость 3)
users := make([]string, 3, 5)         // длина 3, емкость 5

Оператор среза

arr := [8]string{"Bob", "Alice", "Kate", "Sam", "Tom", "Paul", "Mike", "Robert"}

slice1 := arr[2:6]   // с 3-го по 6-й элемент
slice2 := arr[:4]    // с 1-го по 4-й
slice3 := arr[3:]    // с 4-го до конца

fmt.Println(slice1)  // [Kate Sam Tom Paul]
fmt.Println(slice2)  // [Bob Alice Kate Sam]
fmt.Println(slice3)  // [Sam Tom Paul Mike Robert]

Создание среза из другого среза

array := [7]int{1, 2, 3, 4, 5, 6, 7}
slice1 := array[1:6]    // [2, 3, 4, 5, 6]
slice2 := slice1[:3]    // [2, 3, 4]

Добавление элементов (append)

users := []string{"Tom", "Alice", "Kate"}
users = append(users, "Bob")
fmt.Println(users)  // [Tom Alice Kate Bob]

Удаление элемента

users := []string{"Bob", "Alice", "Kate", "Sam", "Tom"}
n := 2  // индекс удаляемого элемента
users = append(users[:n], users[n+1:]...)
fmt.Println(users)  // [Bob, Alice, Tom]

Копирование срезов (copy)

src := []int{1, 2, 3, 4, 5}
dst := make([]int, 3)
n := copy(dst, src)
fmt.Println(dst, n)  // [1 2 3] 3

Важные отличия массивов от срезов

ХарактеристикаМассивСрез
РазмерФиксированныйДинамический
Передача в функциюПо значению (копия)По ссылке
Сравнение (==)ДаНет (только с nil)
Добавление элементовНетДа (append)
