🗺️ Лабораторная работа №5

Карты (maps) и структуры (structs)

Время выполнения: 75 минут
Уровень сложности: Средний
Количество заданий: 15

Цель работы

Изучить хеш-таблицы (карты) и структуры в Go, освоить операции добавления, удаления, поиска и перебора элементов карты, а также создание и использование структур для объединения связанных данных.

📝 Задание 1. Добавление, чтение и удаление элементов

1 Создайте карту students map[int]string, где ключ — ID студента, значение — имя. Выполните операции:

  1. Добавьте 5 студентов с ID от 101 до 105
  2. Выведите студента с ID 103
  3. Измените имя студента с ID 102
  4. Удалите студента с ID 104
  5. Выведите всю карту после всех операций

📝 Задание 2. Перебор карты с упорядочиванием

2 Создайте карту с названиями 7 дней недели на русском языке, где ключ — номер дня (1-7), значение — название. Выведите дни недели в порядке возрастания номеров (от 1 до 7).

📝 Задание 3. Подсчёт голосов

3 Дан список голосов за кандидатов:

votes := []string{"Иванов", "Петров", "Сидоров", "Иванов", "Петров", "Иванов", "Сидоров", "Сидоров", "Петров", "Кузнецов"}

Напишите программу, которая:

  1. Подсчитывает количество голосов за каждого кандидата (используйте карту)
  2. Выводит результаты в формате "Кандидат: количество голосов"
  3. Находит и выводит победителя (кандидата с максимальным количеством голосов)

📝 Задание 4. Инвертирование карты

4 Напишите функцию invertMap(original map[string]int) map[int][]string, которая меняет местами ключи и значения. Учтите, что значения могут повторяться — для одинаковых значений нужно собрать все соответствующие ключи в срез.

Исходные данные: {"a":1, "b":2, "c":1, "d":3, "e":2}

Ожидаемый результат: {1:["a","c"], 2:["b","e"], 3:["d"]}

📝 Задание 5. Определение и использование структуры

5 Определите структуру Book с полями:

  • Title (название, string)
  • Author (автор, string)
  • Year (год издания, int)
  • Pages (количество страниц, int)

Создайте несколько экземпляров структуры (3-4 книги) и выведите их информацию.

📝 Задание 6. Метод для структуры

6 Добавьте к структуре Book метод Info() string, который возвращает строку с информацией о книге в формате:

"Название: Война и мир | Автор: Лев Толстой | Год: 1869 | Страниц: 1225"

Создайте срез из 5 структур Student с полями:

  • Name (string)
  • Group (string)
  • Grades (срез оценок, []int)

Напишите функцию averageGrade(s Student) float64, которая вычисляет средний балл студента. Выведите для каждого студента его имя и средний балл.

📝 Задание 7. Телефонная книга на карте

7 Создайте структуру Contact с полями:

  • Name (string)
  • Phone (string)
  • Email (string)

Создайте карту phoneBook map[string]Contact, где ключ — имя контакта. Реализуйте функции:

  • addContact(phoneBook map[string]Contact, contact Contact)
  • findContact(phoneBook map[string]Contact, name string) (Contact, bool)
  • deleteContact(phoneBook map[string]Contact, name string)
  • printAll(phoneBook map[string]Contact)

В main продемонстрируйте работу всех функций.

📝 Задание 8. Группировка студентов по группам

8 Дан срез студентов (структуры Student из задания 6). Напишите функцию groupByGroup(students []Student) map[string][]Student, которая группирует студентов по группе. Выведите результат: для каждой группы список студентов и их средний балл.

📝 Задание 9. Счетчик слов

9 Реализуйте программу из лекции для подсчета частоты слов в тексте.

Текст: "To be or not to be, that is the question. To be!"

Выведите результат в порядке убывания частоты.

📝 Задание 10. Построитель частотного словаря

10 Напишите программу, которая:

  1. Принимает на вход текст (строку)
  2. Разбивает его на слова
  3. Подсчитывает частоту каждого слова
  4. Выводит топ-5 самых частых слов
  5. Выводит слово, которое встречается реже всего (если несколько — вывести все)

📝 Задание 11. Частотный анализ символов

11 Напишите функцию charFrequency(text string) map[rune]int, которая подсчитывает частоту каждого символа (включая пробелы и знаки препинания) в переданной строке.

В функции main запросите у пользователя строку текста, подсчитайте частоту символов, выведите все символы, которые встречаются более 2 раз, в формате: 'символ': X раз

📝 Задание 12. Фильтрация карты по значению

12 Напишите функцию filterByValue(students map[int]string, minLength int) map[int]string, которая принимает карту студентов (ID → имя) и возвращает новую карту, содержащую только тех студентов, у которых длина имени больше или равна minLength.

Исходные данные:

students := map[int]string{
    101: "Анна",
    102: "Борислав",
    103: "Виктор",
    104: "Елизавета",
    105: "Пётр",
}

Пример: filterByValue(students, 6) должна вернуть карту с ID 102 и 104.

📝 Задание 13. Проверка наличия ключей

13 Напишите функцию hasKeys(m map[string]int, keys []string) bool, которая проверяет, присутствуют ли все ключи из среза keys в карте m.

Исходные данные:

data := map[string]int{"a": 1, "b": 2, "c": 3}
keys1 := []string{"a", "b"}      // true
keys2 := []string{"a", "d"}      // false

📝 Задание 14. Слияние двух карт

14 Напишите функцию mergeMaps(map1, map2 map[string]int) map[string]int, которая объединяет две карты. Если ключ присутствует в обеих картах, значения должны суммироваться.

Исходные данные:

mapA := map[string]int{"a": 1, "b": 2, "c": 3}
mapB := map[string]int{"b": 4, "c": 5, "d": 6}

Ожидаемый результат: {"a":1, "b":6, "c":8, "d":6}

📝 Задание 15. Кэш с ограничением размера (LRU Cache)

15 Реализуйте простой кэш с ограничением максимального количества элементов. При добавлении нового элемента, если кэш переполнен, удаляется самый старый элемент (не использовавшийся дольше всего).

Требования:

  1. Структура Cache с полями maxSize int и data map[string]string
  2. Метод Set(key, value string) — добавляет элемент в кэш
  3. Метод Get(key string) (string, bool) — получает элемент из кэша
  4. При добавлении элемента обновляется время его последнего использования

Итог лабораторной работы

После выполнения лабораторной работы студент умеет создавать карты разными способами (объявление nil-карты, через make, литерал), выполнять добавление, чтение, изменение и удаление элементов, проверять существование ключа с помощью идиомы comma ok. Студент знает, что порядок перебора карты не гарантируется, и умеет упорядочивать вывод путём сортировки ключей. Студент умеет объявлять структуры, создавать их экземпляры, добавлять методы к структурам с получателем-значением и получателем-указателем. На практике студент реализует частотный анализ текста, группировку данных, инвертирование карты, слияние карт, а также создаёт простой кэш с ограничением размера.
