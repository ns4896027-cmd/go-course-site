⚙️ Лабораторная работа №3

Управляющие конструкции и функции

Время выполнения: 60 минут
Уровень сложности: Начинающий
Количество заданий: 10 + мини-проект

Цель работы

Освоить управляющие конструкции языка Go: условные операторы, циклы, оператор выбора switch, а также научиться создавать и использовать функции.

📝 Задание 1. Определитель четности

1 Напишите программу, которая запрашивает у пользователя целое число и выводит:

  • "Число четное", если число делится на 2
  • "Число нечетное", если число не делится на 2

📝 Задание 2. День недели через switch

2 Напишите программу, которая запрашивает номер дня недели (1-7) и выводит его название.

📝 Задание 3. Калькулятор с if-else

3 Напишите программу-калькулятор, которая:

  • Запрашивает два числа
  • Запрашивает операцию (+, -, *, /)
  • Выводит результат

Требования: Использовать if-else для выбора операции. Обработать деление на ноль и неизвестную операцию.

Введите первое число: 10
Введите второе число: 3
Введите операцию (+, -, *, /): *
Результат: 10 * 3 = 30

📝 Задание 4. Таблица умножения (функция)

4 Напишите функцию printMultiplicationTable(n int), которая выводит таблицу умножения для числа n от 1 до 10. Вызовите эту функцию для чисел 3, 5 и 7.

Пример вывода для n=3:
3 x 1 = 3
3 x 2 = 6
...
3 x 10 = 30

📝 Задание 5. Сумма положительных чисел

5 Напишите программу, которая:

  • Создает массив из 10 целых чисел (на выбор)
  • С помощью цикла for range находит сумму только положительных чисел
  • Используйте continue для пропуска отрицательных чисел

📝 Задание 6. Поиск первого большего числа

6 Напишите программу, которая:

  • Создает массив [10]int{5, 12, 8, 3, 15, 7, 9, 4, 11, 6}
  • Запрашивает у пользователя пороговое число threshold
  • Находит и выводит первый элемент массива, который больше threshold
  • Используйте break для выхода из цикла

📝 Задание 7. Оценка успеваемости

7 Напишите функцию getGrade(score int) string, которая принимает балл (0-100) и возвращает оценку:

  • 90-100 → "Отлично"
  • 75-89 → "Хорошо"
  • 60-74 → "Удовлетворительно"
  • 0-59 → "Неудовлетворительно"

В функции main запросите баллы нескольких студентов (минимум 3) и выведите их оценки.

📝 Задание 8. Таблица умножения (все числа)

8 Напишите программу, которая выводит полную таблицу умножения от 1 до 9 в виде матрицы.

📝 Задание 9. Сумма чисел до первого отрицательного

9 Напишите программу, которая суммирует числа из массива, пока не встретит отрицательное. Используйте break.

Исходный массив: [10]int{10, 20, 30, -5, 40, 50}

Ожидаемый вывод: Сумма до первого отрицательного: 60

📝 Задание 10. FizzBuzz

10 Напишите программу, которая выводит числа от 1 до 100. Но:

  • Если число кратно 3 → выведите "Fizz"
  • Если число кратно 5 → выведите "Buzz"
  • Если число кратно и 3, и 5 → выведите "FizzBuzz"
  • Иначе выведите само число

🎯 Мини-проект: Анализатор текста

⭐ Напишите программу, которая анализирует введенный текст и выводит статистику.

Функционал:

  • Запрашивает у пользователя строку текста
  • С помощью цикла for range подсчитывает:
    • Общее количество символов (включая пробелы)
    • Количество букв (a-z, A-Z)
    • Количество цифр (0-9)
    • Количество пробелов
  • Выводит результаты
Пример:
Введите текст: Hello World 123!
Общее количество символов: 15
Количество букв: 10
Количество цифр: 3
Количество пробелов: 2

Итог лабораторной работы

После выполнения лабораторной работы студент умеет писать условные конструкции любой сложности с использованием if-else и switch, владеет циклом for во всех его формах (классический, while, бесконечный), понимает особенности оператора switch (отсутствие автоматического break, работу fallthrough). Студент умеет создавать функции с параметрами и возвращаемыми значениями, использовать множественные возвращаемые значения, применять неопределённое количество параметров. На практике студент решает типовые алгоритмические задачи: определение чётности, таблица умножения, FizzBuzz, поиск минимального и максимального элементов, фильтрация данных.
