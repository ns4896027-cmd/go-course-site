🔢 Лабораторная работа №2

Базовые типы данных, переменные, константы и операции

Время выполнения: 60 минут
Уровень сложности: Начинающий
Количество заданий: 15

Цель работы

Научиться объявлять переменные целочисленных типов, понимать их диапазоны, работать с числами с плавающей точкой, логическими операциями, константами, iota, комплексными числами, преобразованием типов и битовыми операциями.

📝 Задание 1. Целочисленные типы

1 Объявите переменные следующих типов и присвойте им максимально возможные значения:

  • int8, int16, int32, int64
  • uint8, uint16, uint32, uint64
  • byte, rune

Требования: Использовать полное объявление переменных (var имя тип = значение). Все переменные должны быть выведены на экран.

📝 Задание 2. Числа с плавающей точкой

2 Создайте программу, которая вычисляет площадь круга по формуле: S = π × R²

  • Используйте константу pi типа float64 со значением 3.141592653589793
  • Запросите у пользователя радиус (тип float64)
  • Выведите результат с точностью 3 знака после запятой

📝 Задание 3. Логический тип и условные выражения

3 Объявите переменные типа bool:

  • isGoFun = true
  • isLearningHard = false
  • isWeekend = false

Выполните операции и выведите результат с пояснением:

  • isGoFun && isLearningHard
  • isGoFun || isLearningHard
  • !isGoFun
  • isGoFun && !isLearningHard
  • isWeekend || isLearningHard

Пример вывода: "Результат операции A && B: false, потому что isLearningHard = false"

📝 Задание 4. Константы и iota

4 Используя iota, создайте константы для дней недели. Выведите на экран.

📝 Задание 5. Комплексные числа

5 Объявите два комплексных числа:

var z1 complex64 = 3 + 4i
var z2 complex128 = 5 + 12i

Выполните операции:

  • Сложение: z1 + z1
  • Вычитание: z1 - z1
  • Умножение: z1 * z1
  • Модуль комплексного числа (используйте cmplx.Abs из пакета math/cmplx)
  • Действительная и мнимая части (функции real() и imag())

📝 Задание 6. Преобразование типов и потеря данных

6 Даны переменные:

var a int64 = 9223372036854775807
var b int32 = int32(a)
var c int16 = int16(a)
var d int8 = int8(a)

Выведите значения a, b, c, d. Объясните, почему при каждом преобразовании данные «обрезаются».

Напишите функцию safeConvertInt64ToInt8(x int64) (int8, error), которая возвращает ошибку, если значение не помещается в int8.

📝 Задание 7. Логические операции с коротким замыканием

7 Проанализируйте код:

func f1() bool {
    fmt.Print("f1 ")
    return false
}
func f2() bool {
    fmt.Print("f2 ")
    return true
}
func main() {
    result1 := f1() && f2()
    fmt.Println(result1)
    result2 := f2() || f1()
    fmt.Println(result2)
}

Ответьте на вопросы:

  1. Почему функция f2() не вызывается в первом выражении?
  2. Почему функция f1() не вызывается во втором выражении?
  3. Напишите пример, где порядок вызовов критичен для логики программы.

📝 Задание 8. Преобразование строк и чисел

8 Напишите функцию parseAndSum(input string) (int, error), которая:

  • Принимает строку с числами, разделёнными пробелами (например, "10 20 30")
  • Разбивает строку на числа
  • Суммирует их
  • Возвращает ошибку, если какой-то элемент не является числом

Пример: parseAndSum("10 20 30") // 60, nil

📝 Задание 9. Комплексные числа (арифметика)

9 Даны комплексные числа z1 = 3 + 4i и z2 = 1 - 2i. Вычислите:

  • z1 + z2
  • z1 - z2
  • z1 * z2
  • z1 / z2
  • |z1| (модуль)
  • |z2| (модуль)
  • Аргумент (угол) z1 в радианах (cmplx.Phase)

📝 Задание 10. Комплексные числа (квадратное уравнение)

10 Решите квадратное уравнение ax² + bx + c = 0 для случая с комплексными корнями.

Напишите функцию solveQuadratic(a, b, c float64) (complex128, complex128), которая возвращает два корня (могут быть комплексными).

Проверьте на примере: x² + 2x + 5 = 0 (корни: -1 ± 2i)

📝 Задание 11. Бинарный вывод с форматированием

11 Напишите функцию printBinary(n int, bits int), которая выводит число в двоичном виде с указанным количеством бит.

Пример: printBinary(5, 8) → 00000101

📝 Задание 12. Подсчёт битов (population count)

12 Напишите функцию popCount(x uint64) int, которая подсчитывает количество единиц в двоичной записи числа.

📝 Задание 13. Переполнение с проверкой

13 Напишите функцию addWithOverflow(a, b int64) (sum int64, overflow bool), которая возвращает сумму и флаг переполнения.

Подсказка: Используйте проверку: если a > 0 && b > math.MaxInt64 - a — переполнение.

📝 Задание 14. Парсинг бинарной строки

14 Напишите функцию parseBinaryString(s string) (uint64, error), которая принимает строку из 0 и 1 (например, "1010") и возвращает число.

📝 Задание 15. Битовые флаги (bit flags)

15 Создайте систему прав доступа с использованием битовых флагов:

const (
    Read    = 1 << iota // 1 (001)
    Write               // 2 (010)
    Execute             // 4 (100)
)

Запросите у пользователя три числа (0 или 1) для прав: чтение, запись, выполнение. Сформируйте битовую маску и выведите:

  • Итоговую маску в двоичном виде
  • Проверку, есть ли право на чтение
  • Проверку, есть ли право на запись
  • Проверку, есть ли право на выполнение

Итог лабораторной работы

После выполнения лабораторной работы студент знает все базовые типы данных Go и их диапазоны, умеет объявлять переменные разными способами (полное объявление через var и короткая запись :=), понимает механизм нулевых значений. Студент умеет выполнять преобразование типов с проверкой на переполнение, владеет битовыми операциями и работой с битовыми флагами, а также умеет работать с комплексными числами и выполнять арифметические операции с ними.
