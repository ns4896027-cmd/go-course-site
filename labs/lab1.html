💻 Лабораторная работа №1

Установка Go и настройка среды разработки

Время выполнения: 30 минут
Уровень сложности: Начинающий
Инструменты: Go, VS Code

Цель работы

Научиться устанавливать язык программирования Go и настраивать среду разработки для комфортного написания кода.

📖 Теоретическая часть

Перед началом работы с Go необходимо установить компилятор и настроить среду разработки. Go — компилируемый язык, поэтому для запуска программ требуется компилятор. В этой лабораторной работе мы установим Go, настроим переменные окружения и подготовим удобную среду для разработки в VS Code.

🔧 Ход работы

1. Установка Go

1 Перейдите на официальный сайт Go: https://go.dev/dl/

2 Скачайте установщик для вашей операционной системы:

  • Windows: .msi установщик
  • macOS: .pkg установщик
  • Linux: .tar.gz архив

3 Запустите скачанный файл и следуйте инструкциям на экране.

4 После установки откройте терминал (командную строку) и проверьте версию Go:

go version

Вы должны увидеть что-то вроде: go version go1.22.0 windows/amd64

2. Настройка переменных среды (Windows)

5 Создайте папку для проектов на Go, например: C:\GoWorkspace

6 Внутри созданной папки создайте две подпапки: bin и src

7 Откройте Панель управления → Система и безопасность → Система → Дополнительные параметры системы → Переменные среды

8 Нажмите Создать в разделе «Переменные среды пользователя»

9 Введите:

  • Имя переменной: GOPATH
  • Значение переменной: C:\GoWorkspace (путь к вашей папке)

10 Найдите переменную Path в том же разделе, выделите её и нажмите Изменить. Убедитесь, что путь до папки bin Go присутствует. Обычно это C:\Program Files\Go\bin.

Совет: Для проверки переменных окружения выполните команду в терминале: 
go env

Если GOPATH не установлен, Go создаёт рабочий каталог по умолчанию в ~/go.

3. Установка VS Code и расширения

11 Скачайте и установите Visual Studio Code с официального сайта: https://code.visualstudio.com/

12 Откройте VS Code и перейдите в панель расширений (Ctrl+Shift+X)

13 Найдите расширение Go от Go Team at Google и установите его

14 После установки может появиться сообщение: gopls command is not available. Нажмите на появившуюся кнопку Install для установки необходимых инструментов.

4. Настройка пути Go в VS Code

15 Откройте настройки VS Code (Ctrl+,), затем кликните по значку {} — «Open Settings (JSON)»

16 Добавьте следующие строки:

{
    "go.goroot": "C:\\Go",
    "go.gopath": "C:\\Users\\YourName\\go"
}

Для macOS/Linux:

{
    "go.goroot": "/usr/local/go",
    "go.gopath": "/Users/yourusername/go"
}

Замените пути на ваши реальные пути.

5. Проверка установки

17 Создайте новый файл main.go и напишите:

package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}

18 Откройте терминал в VS Code (Ctrl+`)

19 Выполните команду:

go run main.go
Ожидаемый результат: 
Hello, Go!
